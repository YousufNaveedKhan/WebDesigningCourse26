## 📖 About This Repository

This repository contains the complete classroom code of the **Web Designing Course 2026**, taught by **Yousuf Naveed Khan** (Senior Faculty, Aptech Gulshan 2).

Every lecture is a single, self-contained HTML file. The code was written **live in class**, step by step, together with the students. Each file has comments that explain what each line does, so you can revise any topic on your own.

**Who is this for?**

- 🎓 Students of this batch, to revise any lecture at any time
- 🧑‍💻 Absolute beginners who want to learn web designing from zero
- 👨‍🏫 Teachers looking for a simple, practical lecture flow

### Option 1: Download

1. Click the green **Code** button above, then **Download ZIP**
2. Extract the folder

- **Browser:** latest Google Chrome or Microsoft Edge (press `F12` to open DevTools and the Console)

> 💡 **Tip:** Lectures 24 onwards load Bootstrap and other libraries from a CDN, so you need an internet connection to see them properly.

## ⚠️ Note About Bootstrap Versions

- **Lec 24** uses **Bootstrap 5.3.8** (the current stable version).
- **Lec 25 onwards** uses **Bootstrap 6.0.0-alpha.1**, released in October 2026.

Bootstrap 6 renamed many classes. If you copy code from older tutorials or from AI tools, check these first:

| Bootstrap 5 | Bootstrap 6 |
|-------------|-------------|
| `btn btn-primary` | `btn-solid theme-primary` |
| `btn btn-outline-danger` | `btn-outline theme-danger` |
| `text-primary`, `text-white` | `fg-primary`, `fg-white` |
| `col-md-6`, `col-lg-3` | `md:col-6`, `lg:col-3` |
| `<script src="...">` | `<script type="module" src="...">` |

Bootstrap 6 also needs a modern browser (Chrome / Edge 130+).

## 🤖 AI-Assisted Learning

This course teaches students to use Generative AI **the right way**:

1. Learn the concept in class first
2. Use AI to generate a variation (sample data, a section, a component)
3. Read and **explain every line** the AI gave you
4. Save your prompts in a `prompts.txt` file

> AI is your assistant, not your replacement. If you can't explain the code, don't use it.

---

## 💡 Tips for Students

- Type the code yourself; don't just copy-paste. Your fingers learn too.
- Change values in each lecture (colors, sizes, text) and watch what happens.
- Use the browser **Console** (`F12`) to find JavaScript errors.
- Revise one old lecture every day.
- Put every project online (GitHub Pages / Netlify) and add the link to your CV.
